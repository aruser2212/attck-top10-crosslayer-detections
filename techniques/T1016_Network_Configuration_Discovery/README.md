## Наблюдаемый смысл

Сигнал описывает процесс с указанным текстом команды. Он не подтверждает успешность операции или злонамеренность. Имя executable не удостоверяет происхождение бинарного файла.

Пример строкового входа fixture:

```text
ipconfig.exe /all
```

## Источник и границы

Нативный путь использует Sysmon Event 1 версии 5 и строгий `process-v1`. Сохраняются host/process GUID, timestamp и исходная командная строка. Поля предиката должны быть ASCII; неподдержанный вход отклоняется явно. Пробелы и табы учитываются только в перечисленных формах. Это сопоставление сырого текста, а не разбор Windows argv: цитируемые упоминания и некорректные команды могут оставаться кандидатами, а варианты вне описанных форм могут не совпасть.

Это информационный сигнал наблюдаемой команды, а не самостоятельное доказательство разведки атакующим. Содержимое вывода и его сохранение не видны. Кавычки вокруг самого флага, WMI/PowerShell/API-аналоги и другие формы команд находятся вне покрытия.

## Легитимная активность и проверка

Обычная диагностика сети должна совпадать. Использовать сигнал в контексте родительского процесса, пользователя и серии действий; не превращать каждое совпадение в самостоятельный инцидент.

Ручные ожидания хранятся в [общем Sigma manifest](../../tests/fixtures/sigma/predicates.json), rule ID `06349766-1404-4bcc-a36a-c4da64e8815f`. Отсутствующее обязательное поле даёт Sigma nonmatch, но для строгого process-v1 считается ошибкой профиля; оно не является доказательством легитимной активности. Исполненные проверки приведены в [validation report](../../docs/validation_report.md).

Lifecycle — `test`, validation — `partial`, эксплуатационные TPR/FPR/latency не измерены. Общий Hunt DSL и непрерывный collector этим каталогом не добавляются.
