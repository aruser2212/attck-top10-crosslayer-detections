# План тестирования: T1550 (PtH / PtT)

## Автоматизировано

Команды запускаются из корня репозитория в окружении с dev-зависимостями.

- `python tools/check_sigma.py`: pySigma parsing и [source-scoped predicate fixtures](../../../tests/fixtures/sigma/predicates.json), включая правила этой техники; выполнение Sigma в SIEM не проверяется.

Эти проверки подтверждают поведение перечисленных fixtures. Они не измеряют эксплуатационные TPR/FPR и не доказывают полное покрытие техники.

## Следующий ручной/лабораторный этап — не выполнен

1. Использовать легитимный runas /netonly как benign сценарий LT9/seclogo. Совпадение Sigma ожидаемо для кандидата и не доказывает PtH.
2. Для будущей корреляции 4624/4672 задать join по корректному LogonId/host, порядок и окно. Совместное присутствие двух типов событий у одного пользователя недостаточно.
3. Для PtT сравнить обезличенные TGS-события без AS в коротком окне с обычным повторным использованием cached tickets и потерями DC-телеметрии.
4. First-seen, PtH-корреляция и PtT Hunt ещё не исполняются. Проверять их алерты только после реализации и фиксации ожидаемого результата на положительных и benign данных.
