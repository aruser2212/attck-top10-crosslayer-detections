# T1136.001 — Net Local User-Add Command Candidate

[DetCard](DET-WIN-T1136-LOCAL-USER-ADD-001.yaml) · [Sigma](sigma/win_net_local_user_add.yml) · [План проверки](tests/plan.md)

## Наблюдаемое поведение

Image заканчивается на `\net.exe` или `\net1.exe`. В CommandLine есть `user` между ASCII-пробелами/табами и отдельный `/add`; `/add` поддержан также в конце строки. Отдельный `/domain` с теми же границами исключает событие из локального варианта.

Источник — Windows process creation; для отдельного конечного replay используется строгий Sysmon Event ID 1 версии 5 и профиль `process-v1`. Поля предиката — `Image` и `CommandLine`. [Общее руководство](../../docs/windows-process.md) определяет нормализацию, event identity, ASCII-контракт и Basic replay.

## Интерпретация и ограничения

Имя аккаунта, пароль, порядок всех аргументов и успешность команды не проверяются. Цитируемый `/domain` может влиять на raw-предикат; это не восстановление argv или универсальная классификация local/domain. Кавычки вокруг `/add`, другие интерфейсы создания аккаунта и подтверждение Security 4720 вне покрытия. Ошибочный `/domainSuffix` не считается `/domain`.

Ожидаемое легитимное совпадение: Администратор создаёт разрешённую локальную служебную учётную запись. Такой запуск намеренно остаётся кандидатом.

Алерт означает кандидата с указанным командным текстом. Само имя образа не удостоверяет файл, подпись или подлинность инструмента; Sysmon 1 не показывает успешность всей операции. Lifecycle остаётся `test`, confidence — `low`; эксплуатационная precision/TPR/FPR не измерена. Правило не добавляет общий Hunt DSL, сетевую корреляцию или исключения по одному имени процесса.
