# T1018 — Net View Domain Computer Discovery Command Candidate

Запуск `net.exe`/`net1.exe` с отдельным `view` и текстом `/domain:…`. После двоеточия требуется хотя бы один символ, отличный от пробела/таба; имя домена не валидируется.

## Наблюдаемый смысл

Сигнал описывает процесс с указанным текстом команды. Он не подтверждает успешность операции или злонамеренность. Имя executable не удостоверяет происхождение бинарного файла.

Пример строкового входа fixture:

```text
net.exe view /domain:LAB
```

## Источник и границы

Нативный путь использует Sysmon Event 1 версии 5 и строгий `process-v1`. Сохраняются host/process GUID, timestamp и исходная командная строка. Поля предиката должны быть ASCII; неподдержанный вход отклоняется явно. Пробелы и табы учитываются только в перечисленных формах. Это сопоставление сырого текста, а не разбор Windows argv: цитируемые упоминания и некорректные команды могут оставаться кандидатами, а варианты вне описанных форм могут не совпасть.

Чистое `net view /domain`, просмотр конкретного `\\host`, LDAP/PowerShell discovery и другие способы перечисления не входят в этот предикат. Ответ сети и успешность перечисления не наблюдаются. Кавычки не разбираются: `/domain:""` остаётся текстовым кандидатом, несмотря на пустой аргумент после argv-разбора.

## Легитимная активность и проверка

Инвентаризация компьютеров домена и диагностика helpdesk — ожидаемые легитимные совпадения. Этот низкоприоритетный сигнал полезен вместе с контекстом процесса, пользователя и соседних действий.

Ручные ожидания хранятся в [общем Sigma manifest](../../tests/fixtures/sigma/predicates.json), rule ID `89c24b29-3726-4e2e-b663-cc98ca5b8b54`. Отсутствующее обязательное поле даёт Sigma nonmatch, но для строгого process-v1 считается ошибкой профиля; оно не является доказательством легитимной активности. Исполненные проверки приведены в [validation report](../../docs/validation_report.md).

Lifecycle — `test`, validation — `partial`, эксплуатационные TPR/FPR/latency не измерены. Общий Hunt DSL и непрерывный collector этим каталогом не добавляются.
