## Наблюдаемый смысл

Сигнал описывает процесс с указанным текстом команды. Он не подтверждает успешность операции или злонамеренность. Имя executable не удостоверяет происхождение бинарного файла.

Пример строкового входа fixture:

```text
net.exe localgroup Administrators maintenance-user /add
```

## Источник и границы

Нативный путь использует Sysmon Event 1 версии 5 и строгий `process-v1`. Сохраняются host/process GUID, timestamp и исходная командная строка. Поля предиката должны быть ASCII; неподдержанный вход отклоняется явно. Пробелы и табы учитываются только в перечисленных формах. Это сопоставление сырого текста, а не разбор Windows argv: цитируемые упоминания и некорректные команды могут оставаться кандидатами, а варианты вне описанных форм могут не совпасть.

Локализованные или переименованные группы, SID группы, PowerShell/ADSI и прямые API-вызовы не покрыты. Событие создания процесса не удостоверяет изменение членства. Принадлежность `Administrators` встроенной группе по одному имени не устанавливается.

## Легитимная активность и проверка

Штатное предоставление доступа администратором или системой развёртывания остаётся ожидаемым совпадением. Автоматического allowlist по имени процесса или учётной записи нет.

Ручные ожидания хранятся в [общем Sigma manifest](../../tests/fixtures/sigma/predicates.json), rule ID `a9663284-70f8-4f69-ae3e-f829f396fc72`. Исполненные проверки приведены в [validation report](../../docs/validation_report.md).
