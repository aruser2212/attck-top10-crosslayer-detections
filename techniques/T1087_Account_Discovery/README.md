# T1087.002 — Net User Domain Account Enumeration Command Candidate

Запуск `net.exe`/`net1.exe`, строка которого заканчивается сочетанием `user /domain`. Разделители — один ASCII-пробел или таб; в конце допускается один такой разделитель. Отдельные `/add` и `/delete` исключаются.

## Наблюдаемый смысл

Сигнал описывает процесс с указанным текстом команды. Он не подтверждает успешность операции или злонамеренность. Имя executable не удостоверяет происхождение бинарного файла.

Пример строкового входа fixture:

```text
net.exe user /domain
```

## Источник и границы

Нативный путь использует Sysmon Event 1 версии 5 и строгий `process-v1`. Сохраняются host/process GUID, timestamp и исходная командная строка. Поля предиката должны быть ASCII; неподдержанный вход отклоняется явно. Пробелы и табы учитываются только в перечисленных формах. Это сопоставление сырого текста, а не разбор Windows argv: цитируемые упоминания и некорректные команды могут оставаться кандидатами, а варианты вне описанных форм могут не совпасть.

Именованные запросы `net user alice /domain`, изменение пароля/атрибутов, другие порядки/кавычки аргументов и несколько завершающих разделителей находятся вне узкого контракта. Эта граница выбрана, чтобы широкий `net user … /domain` не выдавался за доказательство enumeration. Вывод команды и успешность запроса не наблюдаются.

## Легитимная активность и проверка

Helpdesk и администраторы регулярно перечисляют доменные аккаунты. Легитимное перечисление остаётся ожидаемым кандидатом низкого приоритета.

Ручные ожидания хранятся в [общем Sigma manifest](../../tests/fixtures/sigma/predicates.json), rule ID `a4a7afd2-690b-4412-aa10-5991dd73bb2d`. Отсутствующее обязательное поле даёт Sigma nonmatch, но для строгого process-v1 считается ошибкой профиля; оно не является доказательством легитимной активности. Исполненные проверки приведены в [validation report](../../docs/validation_report.md).

Lifecycle — `test`, validation — `partial`, эксплуатационные TPR/FPR/latency не измерены. Общий Hunt DSL и непрерывный collector этим каталогом не добавляются.
